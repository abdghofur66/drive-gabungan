Pasang Drive Gabungan milikmu sendiri

Satukan beberapa akun Google Drive dalam satu tampilan. Setiap orang memasang salinannya sendiri, jadi data dan aksesnya hanya milikmu. Gratis, sekitar 15 menit.

1

Deploy ke Cloudflare

±2 menit. Membuat salinan aplikasi di akun Cloudflare-mu.

Deploy to Cloudflare
  1. Login atau daftar Cloudflare.
  2. Di Git account, pilih akun GitHub-mu (atau New GitHub connection jika belum ada).
  3. Isi Project name, misalnya drive-saya. Nama ini jadi nama repo baru di GitHub-mu dan bagian dari alamat aplikasi.
  4. Klik Deploy dan tunggu sampai statusnya Ready.

2

Buat password pemilik

Langsung setelah deploy selesai.

Buka alamat aplikasimu. Halaman pertama meminta password pemilik. Isi dua kali, minimal 8 karakter, lalu klik Simpan dan masuk.

Lakukan segera. Orang pertama yang membuat password menjadi pemilik aplikasi ini.
3

Siapkan Google Cloud

±8 menit, cukup sekali. Ini memberi aplikasimu izin untuk meminta akses Drive.

  1. Buka console.cloud.google.com, buat project baru, misalnya Drive Gabungan.
  2. Buka Google Drive API, klik Enable.
  3. Buka Google Auth Platform → Get started. Isi nama aplikasi dan email, pilih External, isi email kontak, centang persetujuan, lalu Create.
  4. Buka Branding, isi tiga kolom ini dengan alamat aplikasimu, lalu Save:
    • Application home page
    • Application privacy policy link
    • Application terms of service link
  5. Buka Data Access → Add or remove scopes. Di Manually add scopes tempel https://www.googleapis.com/auth/drive, klik Add to table → Update → Save.
  6. Buka Clients → Create client, pilih Web application. Di Authorized redirect URIs klik Add URI dan isi alamat aplikasimu ditambah /oauth/callback. Klik Create.
  7. Muncul Client ID dan Client Secret. Salin keduanya sekarang, simpan sementara di Notepad.
  8. Buka Audience, klik Publish app → Confirm sampai statusnya In production.

5

Hubungkan akun Google Drive

±1 menit per akun.

  1. Klik Hubungkan akun Google di sidebar, lalu pilih akunnya.
  2. Muncul layar "Google belum memverifikasi aplikasi ini". Klik Lanjutan, lalu Buka Drive Gabungan (tidak aman).
  3. Centang izin Google Drive, klik Lanjutkan.
  4. Ulangi untuk akun lain. Setiap akun menambah satu warna di pita penyimpanan.

Pakai domain sendiri opsional

±5 menit. Lewati langkah ini kalau alamat .workers.dev sudah cukup.

Punya domain, misalnya sekolahku.sch.id atau namaku.com? Aplikasimu bisa dibuka dari alamat yang lebih mudah diingat, seperti drive.namaku.com.

Syaratnya, domain itu sudah dikelola di Cloudflare (nameserver-nya mengarah ke Cloudflare). Belum punya domain? Bisa dibeli langsung di Cloudflare, lihat cara beli domain di Cloudflare.

A. Pasang domain di Cloudflare

  1. Buka Workers & Pages, pilih project aplikasimu (misalnya drive-saya).
  2. Buka tab Domains (atau Settings → Domains & Routes), lalu klik Add Domain.
  3. Pilih domainmu, isi Subdomain misalnya drive, lalu klik Add domain.
  4. Tunggu beberapa menit sampai alamat baru bisa dibuka. Sertifikat HTTPS (gembok) dibuat otomatis.

Penjelasan lebih rinci dengan gambar: cara membuat subdomain untuk Cloudflare Worker.

B. Daftarkan alamat baru di Google Cloud

Supaya akun Google tetap bisa dihubungkan dari alamat baru:

  1. Buka Google Auth Platform → Clients, lalu klik client yang dibuat di langkah 3.
  2. Di Authorized redirect URIs klik Add URI, lalu isi https://drive.namaku.com/oauth/callback (sesuaikan dengan alamatmu).
  3. Klik Save. Alamat lama boleh tetap dibiarkan, jadi keduanya bisa dipakai.

Pertanyaan umum

Apakah data saya bisa dilihat orang lain?

Tidak. Password, Client Secret, dan token akun tersimpan di database Cloudflare milikmu sendiri. Pembuat aplikasi ini pun tidak bisa mengaksesnya.

Upload masuk ke akun mana?

Kamu memilih sendiri akun dan folder tujuan setiap kali upload. Pilihan awalnya sudah diisikan otomatis: folder yang sedang dibuka, atau akun yang paling lega kalau kamu berada di halaman utama. Akun yang ruangnya tidak cukup tidak bisa dipilih.

Muncul "redirect_uri_mismatch" saat menghubungkan akun.

Jika baru memasang domain sendiri, pastikan alamat barunya sudah ditambahkan di Google Cloud (langkah 6B). Redirect URI di Google Cloud belum sama persis dengan alamat aplikasimu. Salin ulang dari jendela "Hubungkan ke Google Cloud", atau tunggu 5–10 menit setelah menyimpan.

Akun tertulis "Perlu dihubungkan ulang".

Izin dicabut atau status aplikasi masih Testing. Pastikan statusnya In production, lalu klik Hubungkan akun Google dan pilih akun yang sama.

Lupa password pemilik.

Di Cloudflare, buka D1 SQLite Database, pilih database aplikasimu, buka Console, jalankan DELETE FROM settings WHERE key LIKE 'pw_%'; DELETE FROM sessions; lalu buka aplikasi untuk membuat password baru. Akun Google tetap terhubung.

Apakah benar-benar gratis?

Ya. Paket gratis Cloudflare memberi 100.000 permintaan per hari, jauh di atas kebutuhan pribadi. Ruang penyimpanan tetap dari akun Google Drive-mu.
