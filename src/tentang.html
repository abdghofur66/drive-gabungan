Semua akun Google Drive-mu, dalam satu tempat.

Punya akun Drive pribadi, kantor, dan arsip? Drive Gabungan menyatukannya: lihat total ruang, cari file di semua akun, dan pindahkan file dari akun yang penuh ke yang masih lega.

Yang bisa dilakukan

Semua yang biasa kamu lakukan di Google Drive, ditambah hal-hal yang hanya mungkin jika semua akun disatukan.

Pindah antar akun

Akun hampir penuh? Pindahkan file atau folder ke akun lain dengan sekali seret.

Cari di semua akun

Satu kolom cari untuk semua Drive, sampai ke isi dokumen, dengan filter waktu dan ukuran.

Cadangan otomatis

Folder penting disalin ke akun lain tiap hari atau minggu. Bisa juga dijalankan manual.

Link berbagi sendiri

Bagikan file dengan batas waktu, password, dan jumlah unduhan. Penerima tak perlu akun Google.

Saran merapikan

Temukan file kembar di beberapa akun dan file besar yang setahun tak dibuka.

Pemberitahuan di HP

Dikabari saat akun hampir penuh, aksesnya terputus, atau cadangan selesai.

Datamu tetap milikmu

Drive Gabungan tidak punya server pusat. Setiap orang memasang salinannya sendiri.

Berjalan di akunmu sendiri

Aplikasi dan database ada di akun Cloudflare milikmu. Pembuatnya pun tidak bisa melihat file, password, atau akunmu.

Masuk dengan sidik jari

Selain password, bisa masuk dengan sidik jari atau wajah. Ada kunci otomatis dan daftar perangkat yang sedang masuk.

Hapus tetap bisa dibatalkan

File yang dihapus masuk sampah Google Drive dan bisa dipulihkan, plus tombol Urungkan langsung setelah menghapus.

Terus diperbarui

Fitur baru dikirim otomatis ke salinanmu setiap minggu, tanpa perlu memasang ulang.

Cara memasang

Tidak perlu keahlian pemrograman. Panduan bergambar menuntunmu langkah demi langkah.

Deploy sekali klik

Tekan tombol Pasang di Cloudflare. Aplikasi dan database dibuat otomatis, gratis.

Siapkan Google Cloud

Buat Client ID agar aplikasimu boleh meminta akses Drive. Sekitar 8 menit, sekali saja.

Hubungkan akun

Tambahkan akun Google satu per satu, dan semua ruangnya langsung tergabung.

Siap menyatukan Drive-mu?

Gratis, sumber terbuka, dan bisa dipasang hari ini.
